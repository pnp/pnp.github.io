# Community forum previews

New and updated forum previews are captured from public community destinations on 2026-11-14. Captures focus on forum headings and product navigation, not sign-in screens or individual questions.

Power Platform product links use the forum group URLs published by the community homepage. Dynamics 365 and Power BI link to their official community destinations.

The old Microsoft Graph Q&A URL no longer routes to a Graph-specific category. Its card now links to the official Graph support hub, which publishes current question, feedback, and support routes.

Sources remain flat PNGs. The shared resource-image partial creates responsive 480- and 960-pixel JPEGs, and the common CSS angle and close crop match the existing Forums design.

Older images directly under `static/images` already contain their angle. They remain outside the managed preview pipeline to avoid applying the transformation twice.
