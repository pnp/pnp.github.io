    SDKs

    Find what you need to get started building your own solutions.

    • Fluent UI

      Build consistent, accessible web interfaces with Microsoft's Fluent UI React components, web components, and design utilities.

    • Microsoft 365 Agents SDK

      Build and deploy agents with the Microsoft 365 Agents SDK for .NET, JavaScript, and Python.

    • Microsoft Agent Framework

      Build agents and multi-agent workflows in .NET and Python with tools, memory, orchestration, and human-in-the-loop support.

    • Microsoft Dataverse SDK for .NET

      Work with business data and extend Microsoft Dataverse using the official .NET SDK and client libraries.

    • Microsoft Graph SDK

      Build high-quality, efficient, resilient applications that access Microsoft Graph.

    • PnP Core

      A modern .NET SDK designed to work for Microsoft 365 and provide a unified object model for working with SharePoint Online, abstracting the underlying APIs.

    • PnP Framework

      A .NET library targeting Microsoft 365 containing the PnP Provisioning engine and a ton of other useful extensions.

    • PnPjs

      Call SharePoint, Graph, and Microsoft 365 REST APIs in a type-safe way with fluent libraries. For SPFx, Nodejs, or any JavaScript project.

    • Power Apps Component Framework

      Create reusable code components that extend model-driven and canvas apps with custom controls and richer user experiences.

    • React Reusable Controls

      Build professional-looking web parts and extensions with a set of reusable React controls that can be used in SharePoint Framework (SPFx) solutions.

    • Reusable Property Controls

      Add professional property panes to your web parts with a set of reusable property pane controls that can be used in SharePoint Framework (SPFx) solutions.

    Tools

    Perform tasks with a platform-agnostic command-line interface and with PowerShell.

    • CLI for Microsoft 365

      Configure Microsoft 365, manage SharePoint Framework projects and build automation scripts on Windows, macOS or Linux, using Bash, Cmder or PowerShell.

    • Microsoft Graph PowerShell SDK

      Acts as an API wrapper for the Microsoft Graph APIs for use in PowerShell. Manage identities at scale from automating tasks to managing users in bulk.

    • PnP PowerShell

      700+ PowerShell cmdlets for Microsoft 365, SharePoint Online, Microsoft Teams, Microsoft Project, Security & Compliance, Microsoft Entra ID, and more.

    • Power Platform CLI

      Manage environments, solutions, Dataverse, Power Pages, and code components with Microsoft's Power Platform command-line tools.

    • SP Editor

      Browser extension for managing files (JS, CSS), modifying web/list properties, creating webhook subscriptions, editing web parts on pages, and running PnPjs TypeScript snippets.

    • Work IQ Dev Tools

      Build, validate, and publish Microsoft 365 plugins with preview developer tools. The plugin command interface is currently alpha.
